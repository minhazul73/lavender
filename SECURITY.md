# Security Policy

## Supported Versions
Only the latest release on the `main` branch receives security fixes.

## Reporting a Vulnerability
**Do not open a public GitHub issue for security vulnerabilities.**

Please email the maintainer directly or open a
[GitHub Security Advisory](https://github.com/minhazul73/rn7-linux-dashboard/security/advisories/new).

Include: description, reproduction steps, potential impact, and your
suggested fix if you have one.

You will receive an acknowledgement within 72 hours.
