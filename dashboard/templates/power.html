Destructive Lifecycle Actions

These operations immediately affect the operating system. All running background services, terminal sessions, and network sockets will be terminated.

System Reboot

Restart the operating system. All systemd services will stop cleanly and automatically restart upon boot.

Power Off

Halt the kernel and completely power down all hardware. Turning the device back on requires physical access to press the hardware button.

Suspend to RAM

Put device into low-power sleep state. ⚠️ WiFi and network interface will disconnect; physical power button press required to wake up.
